# Ask Winnie! – frontend

## Run locally
    npm install
    npm run dev
Opens at http://localhost:5173

## Try it
- Login with any username/password. A username containing "admin" (e.g. `admin`) logs in as an admin; anything else is a member.
- Admin: Admin Settings -> all admin pages. Open a profile, click the name, Confirm to view as that member, "Back to Admin" to return.
- Member: bell icon opens the incoming-task pop-up; Tasks -> click a profile next to a task to request a reassignment.

## Backend hookup
All placeholder data (PEOPLE, TASKS, MEETINGS, REQUESTS) is at the top of src/App.jsx.
